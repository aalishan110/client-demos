## Behaviour and checks

Buildless HTML/CSS/JS, responsive at 900px and 600px. Keyboard-operable native accordions, skip link, labelled inputs, focus styles and reduced-motion support. Enquiry opens an encoded WhatsApp draft for visitor review; no automatic messages, booking confirmation or data storage. Gents enquiries route to the gents public number; ladies and packages route to the supplied general number.

JavaScript syntax and local link/asset checks passed. Desktop browser visually reviewed; all images loaded, no horizontal overflow. Accordion expansion and service-to-enquiry preselection verified. Mobile CSS reviewed; no separate emulated mobile viewport used.
