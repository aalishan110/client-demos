# BOROPOOL v5

A separate, more premium visual version at /boropool/v5/. V4 and earlier versions are preserved.

The same visible copy across all 12 pages, the same nine guide records and unchanged public interaction scripts are retained from v4. Design includes a panoramic metropolitan hero, larger editorial type, a featured guide layout, structured service rows, navy destination panels, a contained assessment chapter, company photography and refined guide/form pages. The admin uses a matching warmer palette, larger labels and independent sessionStorage key boropool-admin-v5.

Public forms remain demonstration-only and send/store no information. Admin changes only affect the current browser session. No backend or authentication is implied.

See ASSET-CREDITS.txt for the new hero photograph. Native scripts and RTL support are retained. Sample translations require BOROPOOL editorial approval before production.
