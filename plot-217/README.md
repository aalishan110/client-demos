# Plot 217 — Sector B Residence

Interactive 3D house viewer with separate floors, an exploded view, and an assembled flat-roof view with parapet, mumty and water tank. This revision places the additional ground-floor washroom in the front-right corner beside the lawn and relocates the drawing-room glazing to the right side.

[Open the live viewer](https://aalishan110.github.io/client-demos/plot-217/)

The viewer is self-contained and has no build step. Roof details and vertical dimensions are design assumptions; the source PDF does not provide a roof plan or elevations.
