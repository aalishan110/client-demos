# Bodyfit Gyms — homepage concept

Independent, noindex homepage mockup by aaliSoft for the existing client-demos GitHub Pages site. Not official or endorsed by Bodyfit. Buildless HTML, CSS and JavaScript.

- Official Instagram: https://www.instagram.com/bodyfit_gyms/ — name, black/yellow BFG branding, personal training, group classes, F-8 and G-11, original photography/reel thumbnails. The profile links to the Linktree below.
- Official Facebook: https://www.facebook.com/BodyfitGyms — gym, boot camp, yoga, cardio, Zumba and aerobic classes; public contact numbers 051 8461806 and 0300 5557498. Facebook page ID 111411604116016 resolves to this handle.
- Official Linktree: https://linktr.ee/bodyfitgyms — Bodyfit Gold F8 at 1 Kalim Plaza, Kaghan Road, F-8 Markaz, Islamabad; Bodyfit Gym G11 at 1 Ground Floor, Rehman Plaza, G-11 Markaz, Islamabad; the two original Google Maps links and official social accounts.
- Secondary source: https://www.localgymsandfitness.com/PK/Islamabad/111411604116016/Bodyfit-Gyms — published activity, services and contact references. Direct access was blocked; indexed text was available. Official social profiles were inspected instead for asset collection.

No invented prices, discounts, reviews, trainer credentials, success rates, attendance statistics or availability. Historical Eid offers are excluded. Published hours differ across sources, so visitors are asked to confirm branch hours, women's timings and class schedules with the team. Editorial headlines are concept copy, not claimed official slogans. Personal employee information and temporary follower counts are omitted.

## Interaction

- Branch tabs update verified addresses, original map links, panel labels and inquiry selection. Arrow keys, Home and End work in the tablist.
- Training accordions change the supporting image. Native disclosure controls remain available without JavaScript.
- The mobile navigation supports expanded state, anchor dismissal and Escape.
- Inquiry form creates a URL-encoded WhatsApp draft using the public official business mobile. It never sends messages automatically, stores details, takes payment or confirms bookings. Name is optional. A direct link is available without JavaScript.
- Telephone, official social profiles and maps links are real destinations.
- Reduced motion, visible focus indicators, labelled controls, descriptive image alternatives and a skip link are included.

## Preview

Serve the repository root with a static HTTP server, then open `/bodyfit-gyms/`. No install or build step is required.

## Verification completed

JavaScript syntax and Git whitespace checks passed. Local assets resolved. Desktop browser inspection confirmed all images load and no horizontal overflow at 1280px. A 390px iframe viewport was visually inspected; the mobile menu expanded and closed on navigation. Training accordions changed the supporting image and closed other rows. Branch switching updated the address, map link, ARIA state and inquiry selection. No inquiry was sent to the business.
